COLOPHON

关于这部作品

它不是简历。简历回答"你做过什么"，这部作品想回答"你是谁"——以及它是怎么被做出来的。

Ⅰ艺术家陈述

我叫沈炜丹，计算机专业，2027 届，现在在深圳。我用了一段时间把自己拆开——拆成十章故事，和六块内核。

故事是按时间走的：深圳的天桥、那个夏天的风筝、第一次穿上制服去打工、家教、湛江的树、走廊里快步走、开始举铁、实验室的下午、3 月到 9 月的那条岔路，然后又回到深圳。

内核不是按时间排的，是按"我到底是什么样的人"排的：我允许自己停下、方向是撞出来的、我自己就能亮、碎片也是我的、绕回来的时候、还没画完。

"我一直在让自己忙，因为停下来就要面对。后来我学会了比跑更难的事：允许自己停下。"

这两样东西，我用六种不同的看法讲了六遍——主页、漫画、杂志专访、回顾展、作品集、绘本长卷。它们讲的是同一件事，但它们是六种不同的媒介，不是同一套皮肤换颜色。

六个版本的图片互不重复：故事用一套、内核用一套、事件用一套、回顾展用一套。想一次看完，走漫画六格；想慢慢看，走绘本。

Ⅲ画风与形象

画风参考的是日本动画师 新井陽次郎（Yojiro Arai，pixiv / 推特 ID：pochi1989）——吉卜力出身，做过《借物少女艾莉缇》《风起》，也是《企鹅公路》的角色设计。

我学的不是"画得像他"，是他的三件事：保留绘制过程的痕迹、水彩故意涂出线稿之外、大量留白。这三条反过来正好是"AI 味"的解药——所以每一张的指令里都写死了它们。

形象设定：没有刘海、高高的丸子头，黑色头发，圆脸温和五官——五官来自本人证件照，发型是她要的样子。全站六十六张图里，始终是同一个她。

"那些摔的、断的、难堪的，那又怎样。一片片捡起来收好，那也是我的，独一份。"

Ⅳ字体与配色

标题一律衬线（Georgia / Times / 宋体），正文用系统无衬线。理由很实在：全站零外部依赖，不加载任何网络字体，所以选了每台机器都有、又有书卷气的衬线做标题。

暖纸#f7f0e0
墨棕#241f18
朱红#c8102e
暖金#e8a33c
薄荷#a8d5c2

刻意没有用纯黑：墨棕带一点点暖调，纸白也不是 #fffdf6。纯黑纯灰在屏幕上会发死。

Ⅴ技术选择

形态
纯静态 · 无框架、无构建步骤、无 CDN、无追踪、无 Cookie —— 双击 index.html 就能看
手绘
SVG feTurbulence + feDisplacementMap · 程序化噪声推动像素 —— 边框真的会抖，图片和文字不抖（抖动只作用在伪元素上）
动效
CSS 独立属性分工 · scale 呼吸 / translate 视差 / rotate 歪斜 / transform 倾斜 —— 四个属性各管一件事，互不覆盖
滚动
animation-timeline: view() · 原生滚动驱动，零 JS，跑在合成线程 —— 不支持时自动退回 IntersectionObserver
光标
爪印 SVG · 位置零延迟（瞬移），正中心常驻热点圆点 —— 按 P 可随时换回系统光标
无障碍
prefers-reduced-motion 全量降级 · 跳转链接、可见焦点、图片 alt、键盘可达

Ⅵ制作过程

这部作品是改出来的，不是一次做对的。前后迭代了十几轮，其中几次是推倒重来。

被推翻过什么：最早的作品集画的是"事件"（焊接、种电容、狗枕腿），后来发现那只是"发生了什么"，代表不了人，于是重画成六件"内核"意象。四个版本曾经被灌进同一套内容、用同一批图，变成四个皮肤——也被推翻重做成六种媒介。

图片怎么来的：全部生成，不用网图。做法是"双锚点"——用本人证件照锁五官，用画稿锁笔触与色彩，再逐张指定角度、手部动作与背景细节。逐张串行生成，是为了让同一个人的脸在每一张里都对得上。

最难的一处：让 UI 真的手绘。之前只能靠不对称圆角假装，后来换成 SVG 滤镜推动像素——边框终于会抖了，而文字的可读性一点没丢。

"绕回来的时候，好像在原地——但我已经不是原来那个人了。"
