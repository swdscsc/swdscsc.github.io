EXHIBIT 01 · 嵌入式 / IOT

智能家居 IoT 系统

STM32F103 + ESP8266 通过 MQTT 接入华为云 IoT 平台，完成传感器上报与远程控制双向联调，连续运行稳定。含 FreeRTOS 多任务与外设驱动。

STM32FreeRTOSMQTT华为云
综合材料 · C 与寄存器的艺术 仓库

为什么做

课上点亮 LED 之后，我想知道"设备怎么真正连上云"。目标是能在手机上看到家里的温湿度，并能远程关灯。

具体做了什么

  • STM32F103 采集温湿度/光照，串口以 AT 指令驱动 ESP8266 联网
  • 在华为云 IoT 平台建产品与设备，按平台格式拼 JSON payload 上报属性
  • 订阅平台下发 topic，解析命令并回执，实现云端远程控制
  • FreeRTOS 拆成采集 / 上报 / 控制三个任务，用队列传递数据

踩过什么坑

AT 指令的时序和超时最容易炸，加了重试与断线重连；Wi-Fi 掉线后要能自动恢复，这块我改了三版才稳定。

EXHIBIT 02 · 机器学习

信用卡风控 + SHAP

真实信用卡数据集构建欺诈检测模型，先切分后重采样防数据泄露，以 AUC 为主指标；用 SHAP 做可解释性分析，附 MODEL_CARD 与可复现脚本。

PythonsklearnSHAPStacking
数据装置 · 诚实的 AUC 仓库

难点在哪

欺诈样本只占千分之一点几，模型很容易"全猜正常"还拿高分。所以我把指标口径放在第一位。

具体做了什么

  • 严格先切分、后重采样，只在训练折上做 SMOTE，杜绝数据泄露
  • 对比逻辑回归 / 随机森林 / XGBoost / Stacking 多组模型
  • 用真实标签做 SHAP 解释，输出特征贡献图
  • 写 MODEL_CARD（预期用途 / 指标 / 局限 / 伦理）与一键复现脚本

诚实说明

这批数据本身难分，AUC 大约在 0.85 量级——指标可以复现，脚本和参数都在仓库里。

EXHIBIT 08 · 嵌入式 / IOT

ESP32 嵌入式开发综合实训

基于 ESP32 + ESP-IDF 完成一次完整的组件化嵌入式开发，把驱动 → RTOS → 图形界面 → 联网这条链路走通。

ESP32ESP-IDFFreeRTOSLVGLI2C
ESP32 / IDF 作品

为什么做

课上点亮 LED 之后，我想知道一块 MCU 到底能把多少东西塞进去还能稳定跑。所以给自己定的目标是：一个板子，同时读传感器、刷屏幕、连 Wi-Fi。

具体做了什么

  • 组件化开发 LED / KEY / LCD / WiFi 驱动，FreeRTOS 下做多任务调度
  • QMI8658 三轴传感器经 I2C 采集 X / Y / Z 姿态角，LVGL 实时刷新到 LCD
  • 用图片取模工具生成点阵图、做自定义字体
  • WiFi 接入心知天气 API，把天气显示到屏幕上

踩过什么坑

LVGL 刷新和传感器采集抢同一批资源，屏幕会卡成一帧一帧。后来把 UI 刷新单独拆成一个任务、用队列传数据才顺起来——这是我第一次真切体会到任务优先级。

EXHIBIT 09 · 网络安全 / WEB

AES 加解密演示系统

课程里学完分组密码，我把它做成了一个真正能给别人用的前后端分离 Web 应用：后端三个 REST 接口，前端可视化加解密。

PythonFlaskVueREST密码学
Flask / Vue 作品

为什么做

密码学课上一个尴尬的事实是：听懂原理 ≠ 能写出来。我想把这个等号补上，于是写了可以现场输入明文、生成密钥、加解密对照的小系统。

具体做了什么

  • Flask 提供 /api/generate-key、/api/encrypt、/api/decrypt 三个 POST 接口，PKCS7 填充 + Base64 编解码，flask-cors 处理跨域
  • aes_utils.py 独立实现 CBC 模式：IV 随机生成，IV 与密文拼接后再 Base64
  • 前端 Vue2 + Element-UI + Axios（vue-cli 4.5）做交互页面
  • 参数校验：密钥长度只认 128 / 192 / 256，Base64 格式校验，异常统一返回 code / message / data

踩过什么坑

最难的不是加密本身，而是两端对不齐：填充、编码、IV 的处理只要有一处不一致就解不出来。我专门写了一组固定测试向量做前后端互测，才确认加解密真正对齐。
